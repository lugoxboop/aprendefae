### 4 · C.8, p. 265 — Inventarios

**Enunciado:** Una empresa tiene estos datos del periodo. ¿Cuál es el Costo de mercancía vendida?

**Datos**, en el orden del estado de resultados (decisión de Itagaki, confirmada por Kamogawa: apartar los datos que no entran regalaría la respuesta):

| Etiqueta | Cifra |
|---|---|
| Ventas | $11.400 |
| Devoluciones de ventas | $1.000 |
| Inventario inicial | $500 |
| Compras | $4.000 |
| Devoluciones de compras | $300 |
| Inventario final | $800 |

| | Opción | Retroalimentación |
|---|---|---|
| ✓ | $3.400 | Bien. Lo que tú tenías para vender era $4.200. De eso, quedaron $800 en la bodega. Lo que sí vendiste costó $3.400. Las ventas no van aquí. |
| ✗ | $2.400 | Restaste las devoluciones de ventas. Esas no tocan el costo: afectan las ventas. El costo solo usa inventarios, compras y devoluciones de compras. |
| ✗ | $6.400 | Esa cifra es imposible. Lo más que pudiste vender es lo que tenías disponible: 500 + 4.000 − 300 = $4.200. Ningún costo de lo vendido pasa de ahí. Revisa si usaste las ventas: no entran al cálculo. |
| ✗ | $6.000 | Esta cifra también pasa del disponible ($4.200), así que no puede ser. Revisa dos cosas. El inventario final se resta: es lo que no se vendió. Y las devoluciones de ventas no entran al costo. |

**Pista:** Separa los datos en dos grupos: los de comprar y guardar, y los de vender. Solo un grupo sirve.

*De dónde salen los distractores (Miyata): $2.400 = 3.400 − 1.000, seguro. $6.000 = 500 + 4.000 − 300 + 800 + 1.000, el más probable, no el único. $6.400 no se pudo reconstruir con certeza y **no se le inventa origen**: su retroalimentación se apoya en el tope del disponible, que es verificable.*
